🔧 Kiểm tra API

Nhấn các nút bên dưới để test các phương pháp khác nhau:

🚀 Hướng dẫn Setup

Phương pháp 1: Sử dụng PHP (Khuyến nghị)

Nếu server hỗ trợ PHP, API đã được tạo sẵn tại api/get-media-files.php

# Đảm bảo server web (Apache/Nginx) hỗ trợ PHP # File api/get-media-files.php sẽ tự động hoạt động

Phương pháp 2: Sử dụng Node.js

Chạy server Node.js để cung cấp API:

cd api
node media-server.js

Sau đó sửa đường dẫn API trong gallery.js từ api/get-media-files.php thành http://localhost:3000/api/get-media-files

Phương pháp 3: Directory Listing

Nếu server web cho phép directory listing, gallery sẽ tự động parse HTML listing.

📁 Cấu trúc thư mục

Đảm bảo cấu trúc thư mục như sau:

bangduyen.memories/
├── data/
│ ├── images/ ← Thêm ảnh vào đây
│ │ ├── photo1.jpg
│ │ ├── photo2.png
│ │ └── ...
│ └── videos/ ← Thêm video vào đây
│ ├── video1.mp4
│ ├── video2.webm
│ └── ...
├── api/
│ ├── get-media-files.php
│ └── media-server.js
└── gallery.html
