# 🚀 Setup Gallery cho GitHub Pages

## 📋 Tóm tắt

Gallery đã được tối ưu để hoạt động hoàn toàn trên **GitHub Pages** với 2 phương pháp:

1. **🤖 Tự động (GitHub Actions)** - Khuyến nghị
2. **📡 Manual (GitHub API)** - Backup

## 🎯 Phương pháp 1: GitHub Actions (Tự động)

### Setup:

1. **Push code lên GitHub repository**
2. **Bật GitHub Pages** trong Settings
3. **GitHub Actions sẽ tự động chạy** khi có file mới trong `data/images/` hoặc `data/videos/`

### Cách hoạt động:

```
📁 Thêm ảnh vào data/images/
     ↓
🤖 GitHub Actions tự động chạy
     ↓
📄 Tạo file api/media-files.json
     ↓
🌐 Gallery tự động hiển thị ảnh mới
```

### Files sử dụng:
- **HTML**: `gallery-github-pages.html`
- **JS**: `gallery-github-pages.js`
- **Workflow**: `.github/workflows/update-media-list.yml`

## 🔧 Phương pháp 2: GitHub API (Manual)

### Setup:

1. Sửa file `github-pages-gallery.js`
2. Cập nhật thông tin repository:

```javascript
this.config = {
  owner: 'pvbang',              // ← Thay bằng username GitHub của bạn
  repo: 'bangduyen.memories',   // ← Thay bằng tên repo của bạn
  branch: 'main',               // ← Hoặc 'master'
  imagesPath: 'data/images',
  videosPath: 'data/videos'
};
```

### Files sử dụng:
- **HTML**: Sử dụng `gallery.html` và đổi script thành `github-pages-gallery.js`
- **JS**: `github-pages-gallery.js`

## 📁 Cấu trúc GitHub Repository

```
your-repo/
├── .github/

│       └── update-media-list.yml    ← GitHub Actions

├── api/
│   └── media-files.json             ← Auto-generated by GitHub Actions

└── README.md
```

## 🎮 Cách sử dụng

### Thêm ảnh/video mới:

#### GitHub Actions (Tự động):
1. **Upload ảnh** vào `data/images/` qua GitHub web interface hoặc git push
2. **GitHub Actions tự động chạy** (trong vài phút)
3. **Refresh trang** - ảnh mới sẽ hiển thị!

#### GitHub API (Manual):
1. **Upload ảnh** vào `data/images/`
2. **Refresh trang** - GitHub API sẽ tự động lấy danh sách mới

### Xem website:
```
https://your-username.github.io/your-repo-name/gallery-github-pages.html
```

## 🔍 Kiểm tra GitHub Actions

### Xem Workflow:
1. Vào tab **Actions** trong GitHub repository
2. Xem workflow **"Update Media Files List"**
3. Kiểm tra log để đảm bảo chạy thành công

### Manual trigger:
1. Vào **Actions** → **Update Media Files List**
2. Click **"Run workflow"**
3. Chọn branch và click **"Run workflow"**

## 🐛 Troubleshooting

### GitHub Actions không chạy:
- ✅ Kiểm tra file `.github/workflows/update-media-list.yml` có đúng format
- ✅ Đảm bảo có file trong `data/images/` hoặc `data/videos/`
- ✅ Kiểm tra tab Actions có lỗi không

### GitHub API không hoạt động:
- ✅ Kiểm tra thông tin repo trong `config` có đúng không
- ✅ Đảm bảo repo là public (hoặc có quyền truy cập)
- ✅ Xem Console (F12) có lỗi API không

### Gallery không hiển thị ảnh:
- ✅ Kiểm tra file `api/media-files.json` có được tạo không
- ✅ Xem Console có lỗi JavaScript không
- ✅ Đảm bảo đường dẫn ảnh đúng format

## 🌟 Lợi ích GitHub Pages

### ✅ Ưu điểm:
- **Miễn phí** và **không giới hạn** bandwidth
- **Tự động deploy** khi push code
- **HTTPS** tự động
- **CDN** toàn cầu
- **Không cần server** riêng

### ⚠️ Giới hạn:
- Chỉ **static files** (HTML, CSS, JS)
- **Không có PHP** hoặc server-side code
- **File size limit**: 100MB/file, 1GB/repo
- **Bandwidth**: 100GB/tháng

## 🚀 Deployment Steps

### Lần đầu setup:

1. **Push all files** lên GitHub repository
2. **Enable GitHub Pages** (Settings → Pages → Source: Deploy from a branch → main)
3. **Wait for deployment** (vài phút)
4. **Access website**: `https://username.github.io/repo-name/gallery-github-pages.html`

### Thêm ảnh mới:

1. **Upload files** vào `data/images/` (qua GitHub web hoặc git push)
2. **Wait for GitHub Actions** (1-2 phút)
3. **Refresh page** → Ảnh mới xuất hiện!

## 📊 Monitoring

### GitHub Actions Status:
- ✅ **Success**: File JSON được tạo thành công
- ⚠️ **Warning**: Không có file mới
- ❌ **Failed**: Lỗi trong script

### Website Status:
- 🟢 **API Success**: Tải từ GitHub Actions JSON
- 🟡 **API Fallback**: Sử dụng GitHub API
- 🔴 **Fallback**: Sử dụng danh sách tĩnh
